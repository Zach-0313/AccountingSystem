# Accounting Software

A simple and efficient accounting software built using React.js for the front-end and Supabase for the database backend.

## Features

- User authentication (Sign up, login, and logout)
- Create, update, and delete transactions
- Responsive design
- Secure database using Supabase

## Technologies Used

- **React.js** - Front-end JavaScript library for building user interfaces
- **Supabase** - Backend as a service for database, authentication, and more
- **Vite** - Build tool for fast development and optimized production builds

## Installation

### Prerequisites

Make sure you have the following installed:
- **Node.js** (v16 or higher)
- **npm**

### Steps

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/accounting-software.git
   cd accounting-software
2. **Install Dependencies**
   ```bash
   npm i
3. Run the app
   ```bash
   npm run dev
